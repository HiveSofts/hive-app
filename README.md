# 🐝 Hive

### Cross-platform local development environment for modern web applications

![Hive Logo](https://raw.githubusercontent.com/LaraPire/hive-art/main/Hive-Logo.png)

---

## ✨ About

**Hive** is a lightweight, powerful desktop application designed to simplify modern web development.

No more spending hours configuring local environments, managing ports, switching between runtimes, or remembering complicated commands.

Hive gives developers a clean and organized workspace where they can manage their projects, services, runtimes, tunnels, and development tools from one place.

Add your project — Laravel, Next.js, React, Node.js, or any modern web application — and Hive creates a beautiful local development experience with automatic domains like:

```
your-project.test
```

Built with performance, simplicity, and developer experience in mind.

---

## 🚀 Why Hive?

Modern development environments can become messy quickly:

* Different PHP versions
* Node.js version conflicts
* Manual hosts configuration
* Port management
* Docker complexity
* Repetitive setup steps
* Too many terminal commands

Hive tries to make local development feel simple again.

Open Hive → Add your project → Start coding.

That's it. 🐝

### 🔥 Hive CLI

Hive also includes a powerful command-line companion.

Examples:

```bash
hive init
```

Initialize a project.

```bash
hive run
```

Run your development environment.

```bash
hive logs
```

View project logs.

```bash
hive expose
```

Create a public tunnel for local development.
